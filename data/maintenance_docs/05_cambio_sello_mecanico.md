# Procedimiento de Cambio de Sello Mecánico en Bombas

## 1. Objetivo
Describir el procedimiento paso a paso para el reemplazo del sello mecánico en bombas centrífugas API 610.

## 2. Tipos de Sellos Instalados
- P-101A/B: John Crane 5610 (sello doble, plan API 53B)
- P-102: Flowserve ISC2 (sello simple, plan API 11)
- P-201/202: Eagle Burgmann M7N (sello doble, plan API 54)
- P-301: John Crane 5610 (sello simple, plan API 32)

## 3. Preparación
1. Generar orden de trabajo y permiso de trabajo
2. Realizar análisis de riesgo (JSA)
3. Verificar disponibilidad del kit de sello en almacén
4. Aislar eléctricamente el motor (LOTO)
5. Cerrar y bloquear válvulas de succión y descarga
6. Drenar la bomba completamente
7. Despresurizar sistema de sello (plan API)
8. Verificar cero energía con lista de verificación

## 4. Desmontaje del Sello
1. Retirar guarda de acople
2. Desconectar tubing del plan de sellos
3. Aflojar pernos de tapa de sello (prensa-estopa)
4. Retirar tapa de sello
5. Extraer sello mecánico:
   - Parte rotatoria: sale con el eje
   - Parte estacionaria: queda en la cámara de sello
6. Inspeccionar caras del sello: buscar marcas, rayaduras, carbonización
7. Inspeccionar camisa del eje: buscar desgaste o surcos
   - Si runout de camisa > 0.025mm: reemplazar

## 5. Instalación del Sello Nuevo
1. Limpiar cámara de sello meticulosamente
2. Verificar dimensiones del sello nuevo vs especificación
3. Lubricar O-rings con lubricante compatible (NO usar grasa de petróleo con elastómeros)
4. Instalar parte estacionaria en la cámara de sello
5. Deslizar parte rotatoria sobre la camisa del eje
6. Ajustar la longitud de trabajo del sello según manual OEM:
   - Distancia de referencia: ver plano de instalación
   - Utilizar galga de setting proporcionada en el kit
7. Apretar set screws de la parte rotatoria al eje (torque: consultar manual)
8. Instalar tapa de sello y apretar pernos (patrón en estrella)
9. Reconectar tubing del plan de sellos

## 6. Puesta en Servicio
1. Activar el sistema de plan de sellos:
   - Plan API 53B: presurizar con gas nitrógeno a presión de barrera
   - Plan API 11: verificar circulación
2. Abrir válvula de succión lentamente
3. Verificar ausencia de fuga por sello
4. Arrancar la bomba siguiendo procedimiento de arranque
5. Monitorear temperatura del sello durante primera hora de operación:
   - Normal: 40-60°C
   - Alarma: > 80°C
6. Verificar vibración post-arranque

## 7. Documentación
- Registrar marca, modelo y número de lote del sello instalado
- Registrar holguras medidas y ajuste de setting
- Documentar hallazgos del sello removido (fotos)
- Actualizar registro de vida útil del sello en SAP
- MTBF objetivo para sellos mecánicos: > 18 meses
